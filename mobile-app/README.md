# Mobile App Placeholder

The mobile experience is not implemented yet. This directory acknowledges that intention and avoids the confusion of an empty tree.

Suggested bootstrap steps when mobile work begins:
1. Initialize a React Native app (`npx react-native init hissabiMobile`) or Expo project.
2. Mirror authentication flows from the web app via the shared API client patterns.
3. Share UI primitives (typography, colors) with the web app via a design tokens package.
